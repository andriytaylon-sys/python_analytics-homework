Автоматизація комерційних показників та щотижневої звітності (Python / Pandas)
 Опис проєкту
Цей проєкт присвячений розробці аналітичного модуля на Python для автоматизації попередньої обробки (Data Preprocessing), очищення сирих комерційних даних та формування динамічної щотижневої звітності для менеджменту компанії. 
Скрипт дозволяє повністю замінити рутинну ручну роботу в Excel, мінімізувати ризик людської помилки та миттєво отримувати чисті аналітичні зрізи щодо ефективності бізнес-процесів.
Технологічний стек
  Мова програмування: Python
  Основні бібліотеки: Pandas, NumPy
  Середовище розробки: Google Colab / Jupyter Notebook
   Виконана робота та ключова логіка коду
В ході реалізації проєкту було виконано наступні аналітичні та технічні завдання:
1. Динамічний розрахунок метрик:* Реалізовано логіку обчислення фінальних бізнес-показників (`Final Score`) на основі багатофакторного аналізу (комерційні параметри, локація, соціально-демографічні критерії та індустрії замовників).
2. Алгоритм маскування та валідації даних: Створено булеві маски (`valid_mask`) з використанням методів `.notna()` для автоматичного відсікання пустих значень сум (`Amount`) та некоректних транзакцій перед фінальним аналізом.
3. Трансформація часових інтервалів: Написано алгоритм конвертації сирих дат у фіксовані часові інтервали (номери тижнів року) за допомогою `.dt.isocalendar().week`.
4. Щотижнева агрегація (Групування): Застосовано зв'язку методів `.groupby()` та `.mean()` для формування підсумкового щотижневого звіту (`weekly_report`) з розрахунком середніх рейтингів прийнятих заявок.
   Результат для бізнесу
Створено готовий автоматизований pipeline, який самостійно трансформує «брудні» транзакційні масиви у готові бізнес-зрізи. Це дозволяє компанії:
 Скоротити час на підготовку регулярної звітності.
 Оцінювати динаміку комерційних показників у розрізі тижнів у реальному часі.
